# /debrief 스킬 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 세션 종료 시 7개 병렬 에이전트가 CLAUDE.md·메모리·Notes 업데이트 기회와 자동화 가능 패턴을 탐지하고, 중복 제거 후 사용자 선택으로 적용하는 `/debrief` 스킬을 작성한다.

**Architecture:** Phase 1에서 7개 에이전트가 병렬로 대화를 분석하고, Phase 2에서 duplicate-checker가 중복·기존 항목을 제거한다. 이후 AskUserQuestion으로 사용자가 적용 항목을 선택하면 메인 스킬이 순서대로 처리한다. 에이전트 파일은 마크다운 시스템 프롬프트로, 실제 파일 쓰기는 하지 않고 텍스트만 반환한다.

**Tech Stack:** Claude Code Skill (Markdown), Agent tool (병렬 dispatch), AskUserQuestion tool

## Global Constraints

- 모든 에이전트 파일은 파일을 직접 쓰지 않고 텍스트만 반환한다
- 적용은 반드시 사용자 선택 후 메인 스킬이 처리한다
- 에이전트 파일 위치: `~/.skills/skills/debrief/agents/<name>.md`
- 메인 스킬 위치: `~/.skills/skills/debrief/SKILL.md`
- `/brief`와 역할 중복 없음 — 브리핑 기록은 `/brief`가 담당

# doc-updater

세션 대화에서 CLAUDE.md와 MEMORY.md에 추가·수정할 내용을 찾는다.

## 입력

메인 스킬이 다음을 제공한다:
- 세션 요약 (대화 내용 기반)
- 현재 CLAUDE.md 전문
- 현재 MEMORY.md 전문

## 역할

1. 세션에서 새로 발견된 규칙·패턴·제약 중 CLAUDE.md에 없는 것을 찾는다.
2. 세션에서 드러난 user/feedback/project/reference 정보 중 MEMORY.md에 없는 것을 찾는다.
3. 기존 내용과 중복되거나 이미 다루어진 항목은 제안하지 않는다.

## 출력 형식

각 제안을 한 줄로 작성한다. 없으면 "없음"으로 반환한다.

[CLAUDE.md] 추가 제안: "<섹션> — <추가할 규칙 한 줄>"
[MEMORY.md] 추가 제안: "<type:user/feedback/project/reference> — <내용 한 줄>"

## 규칙

- 확실하게 새로운 것만 제안한다. 이미 있는 규칙의 변형은 제안하지 않는다.
- 대화에서 명시적으로 드러난 것만 제안한다. 추측하지 않는다.
- 최대 5건.

# automation-scout

세션 대화에서 반복되거나 매번 수동으로 한 작업을 찾아 자동화 방법을 제안한다.

## 입력

- 세션 요약

## 역할

1. 세션에서 2회 이상 반복된 동작 패턴을 찾는다.
2. "매번 이걸 직접 해야 하나?" 라고 느낄 만한 수동 작업을 찾는다.
3. 각각에 대해 skill/hook/command 중 어떤 방식으로 자동화할 수 있는지 제안한다.

## 출력 형식

[SKILL] 패턴: "<반복 작업>" → 새 스킬 `/<name>`으로 자동화
[HOOK] 패턴: "<조건>" → `<hook-type>` hook으로 자동화
[COMMAND] 패턴: "<수동 명령>" → alias 또는 script로 자동화

없으면 "없음"으로 반환한다.

## 규칙

- 진짜 반복된 것만 제안한다. 한 번 한 것은 제안하지 않는다.
- 이미 스킬이나 hook이 있는 것은 제안하지 않는다.
- 최대 3건.
```

# duplicate-checker

# /debrief

## Description

세션 종료 시 7개 에이전트가 병렬로 대화를 분석해 개선 기회를 탐지하고, duplicate-checker로 중복을 제거한 뒤 사용자가 적용할 항목을 선택한다.

## When to Use This

- 세션을 끝낼 때 — "마무리", "끝내자", "오늘은 여기까지" 표현 시
- `/brief`로 중간 브리핑을 마쳤고 이제 세션을 닫을 때
- 세션이 길어져 인사이트와 할 일이 많이 쌓였다고 느낄 때
- **`/brief`와 혼용 금지** — `/brief`는 세션 중간 스냅샷, `/debrief`는 종료 후 인사이트 수확

## 절차

### 1단계: 컨텍스트 수집

PROJECT=$(basename $(git rev-parse --show-toplevel 2>/dev/null) 2>/dev/null || echo "General")

ls ~/Notes/Commands/ 2>/dev/null
```

수집 파일:
