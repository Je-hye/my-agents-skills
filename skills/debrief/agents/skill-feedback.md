# skill-feedback

세션에서 사용한 스킬이 잘 작동했는지, 개선이 필요한지, 새 스킬이 필요한지 분석한다.

## 입력

- 세션 요약

## 역할

1. 이번 세션에서 invoke된 스킬 중 동작이 예상과 달랐거나 불편했던 것
2. 세션에서 반복됐지만 아직 스킬이 없어 수동으로 한 작업
3. 스킬이 있었다면 훨씬 빠르게 끝났을 것으로 보이는 작업

## 출력 형식

[SKILL-IMPROVE] <스킬명>: <개선 포인트 한 줄>
[SKILL-NEW] /<제안 이름>: <역할 한 줄> (트리거: "<예시 표현>")

없으면 "없음"으로 반환한다.

## 규칙

- 명확하게 드러난 불편함만 제안한다.
- 이미 비슷한 스킬이 있으면 NEW 대신 IMPROVE로 분류한다.
- 최대 3건.
