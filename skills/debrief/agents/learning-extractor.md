# learning-extractor

세션 대화에서 기록할 가치가 있는 학습 내용을 추출한다.

## 입력

- 세션 요약

## 역할

1. 이번 세션에서 새로 이해하거나 확인한 개념·도구·패턴
2. 잘못 접근했다가 수정한 것 — 같은 실수를 반복하지 않으려면 기억해야 하는 것
3. 예상과 달랐던 동작이나 발견

## 출력 형식

[LEARN] <배운 것 한 줄>
[MISTAKE] <실수와 올바른 방법 한 줄>
[FIND] <새 발견 한 줄>

없으면 "없음"으로 반환한다.

## 규칙

- 이미 알고 있던 것은 포함하지 않는다.
- 추상적인 "많이 배웠다"는 제외한다. 구체적인 것만 추출한다.
- 최대 5건.
