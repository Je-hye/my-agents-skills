# 시각자료 정책

- 승인된 사용자 사진을 우선하고 원본을 덮어쓰지 않는다.
- 사진별 권리, 인물 게시 동의, 개인정보, 삽입 위치, 크롭·가림·보정 요청을 기록한다.
- 사진 권리·동의·개인정보 중 하나라도 미해결이면 해당 사진을 제외하거나 `blocked` 처리한다.
- 이미지 생성·편집이 필요할 때만 `imagegen` 스킬을 읽고 내장 GPT 이미지 생성 도구를 우선한다.
- 실존 학생·강사의 얼굴이나 실제 수업 장면을 추정 생성하지 않는다.
- 사용자 사진과 GPT 삽화는 별도 파일로 유지한다. 합성은 명시적 요청과 개인정보 검사를 모두 요구한다.
- 생성 이미지를 실제 현장 사진처럼 표시하지 않는다.
- 이미지 속 한글, 과학 표현, 본문과의 사실 일치를 확인한다.
- 각 파일에 출처, 삽입 위치, 대체텍스트, 개인정보 처리 상태를 기록한다.
- 카드뉴스와 단순 텍스트 카드를 만들지 않는다.
- 글의 흐름을 설명하거나 이해를 돕는 경우에만 삽화를 넣고, 장식 목적의 반복 이미지는 제외한다.
