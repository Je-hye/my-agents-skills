# 콘텐츠 정책

## 사실과 출처

- 제공되지 않은 사례, 후기, 성과, 가격, 일정, 연락처, 실제 발언을 만들지 않는다.
- 최신 외부 사실은 공식·1차 출처를 우선하고 URL과 확인 날짜를 남긴다.
- 확인되지 않은 정보는 `[확인 필요: 항목]`으로 표시한다.
- 경쟁 학원 문구를 복제하거나 비방하지 않는다.

## 개인정보와 승인

- 학생·학부모·강사의 이름, 얼굴, 학교, 성적 등 식별 정보는 게시 동의 없이 사용하지 않는다.
- 사진 권리와 식별 가능한 인물의 게시 동의를 추정하지 않는다.
- 승인 게이트를 건너뛰지 않는다. 승인 전 다음 외부 영향 단계로 진행하지 않는다.
- 승인된 게시 패키지는 사용자가 네이버 블로그에 직접 복사·붙여넣는다. 네이버 편집기 입력과 발행·예약 발행은 수행하지 않는다.

## 작성 원칙

- 친근한 존댓말과 쉬운 한국어를 사용한다.
- 첫 1~2문단에서 독자의 질문과 핵심 가치를 제시한다.
- 한 문단에 한 가지 생각을 두고 구체적인 확인 정보로 설명한다.
- 검색어 반복보다 독자가 필요한 일정·대상·준비물·신청 방법을 찾기 쉽게 쓴다.
